Prepared CLI source executables and SHA256SUMS may live under downloads/ for local
build/deployment helpers. They are not embedded separately. The only embedded
component archive is internal/components/assets/components.tar.xz.

All component packing is owned by scripts/build_components.py and cmd/agenterm-pack.
At runtime, installers choose supported formats or direct source downloads; the
server packs only requested formats and caches the generated bytes in memory.
See internal/components/assets/README.txt for the build and startup workflow.
