## 接入 Agent

### 🤖 让 Agent 帮你配置

将下面的内容发给你的 Agent：

```text
请帮我把 Agenterm 配置为当前 Agent 的 MCP 服务，使用 Streamable HTTP，地址是 https://agenterm.net/mcp。请保留已有配置，完成后检查连接状态，并告诉我是否需要重启或重新加载。配置完成并连接成功后，请生成一个远程邀请令牌。
```

### ⚙️ 手动配置

以下示例使用 Agenterm 托管服务。已有配置文件时，只需合并对应的 `agenterm` 条目，不要覆盖其他配置。

**Codex**：在终端运行（适用于 CLI 和 IDE 扩展）：

```sh
codex mcp add agenterm --url https://agenterm.net/mcp
```

**Claude Code**：在终端运行，添加到当前用户的所有项目：

```sh
claude mcp add --transport http --scope user agenterm https://agenterm.net/mcp
```

**Gemini CLI**：在终端运行，添加到用户配置：

```sh
gemini mcp add --transport http --scope user agenterm https://agenterm.net/mcp
```

添加后重新加载 MCP 配置或重启 Agent，并在其 MCP 设置中确认连接状态。其他支持 Streamable HTTP 的 Agent 也可以使用相同地址。

使用自托管服务时，将地址替换为部署后显示的 MCP 地址，并按所用 Agent 的方式配置管理密钥；不要将密钥提交到版本管理。

## 🤝 开始远程协助

1. 告诉 Agent 要完成的任务，让它为目标电脑创建邀请。
2. 将 Agent 给出的连接命令或短码地址私下发送给对方。短链接（例如 `example.com/c/abcdef`）可在目标电脑的浏览器中打开，查看连接命令和令牌。单设备客户端在线期间，短链接、短码和连接令牌不能用于新的连接；断线后仍在有效期内时可重新使用。短链接与短码的有效期跟随连接令牌；查看页面不计入兑换次数，客户端第 10 次成功兑换后短码和短链接失效。GET 请求查看页面，客户端通过 POST 兑换；安装脚本使用独立的令牌密钥路径。一键连接命令的有效期取决于连接令牌。短链接包含连接凭证，请仅私下分享给可信任的人。

   单设备客户端与服务端都支持重连凭据时，客户端断线后可用保存在当前进程中的私密凭据恢复连接，即使服务端尚未清理旧连接也能接管。其他设备没有该凭据，不能借此接管。旧客户端或旧服务端不支持此能力；请更新双方以获得可靠的自动重连。
3. 对方运行适合自己系统的命令，阅读提示并确认授权。
4. 保持 Agent 对话进行，等待设备上线后开始任务。对方可在客户端查看命令和输出，随时断开连接。
5. 完成后关闭客户端或断开连接。

需要连接多台电脑时，可以让 Agent 创建多设备邀请，并在操作前说明目标设备。多设备令牌不提供短码。单设备连接的短码默认禁用，须由服务器管理员启用。

连接成功后，客户端会在本地保存 Server 地址。输入 6 位短码时，可从历史列表中选择生成该短码的 Server；客户端只查询选中的 Server，并沿用记录中的 HTTP 或 HTTPS 协议。没有历史记录时，请输入完整短码地址。

## 💻 客户端操作

- 🖥️ **终端客户端：** 在 macOS、Windows 和 Linux 桌面环境中，先不带参数手动启动一次 CLI，注册链接处理程序；之后可在短链接页面选择“打开终端版并连接”。macOS 首次打开时可能请求控制终端的权限。移动可执行文件后需重新启动一次。也可粘贴连接令牌或短码地址连接；使用方向键或鼠标滚轮浏览，拖选文字复制，按 `c` 清空显示，按 `q` 断开并退出。
- 🪟 **桌面客户端：** 在 macOS 和 Windows 上先手动打开一次，注册链接处理程序；之后可在短链接页面选择“打开桌面版并连接”。也可粘贴连接令牌或短码地址（例如 `https://example.com/agenterm/c/XXXXXX`）、连接或断开，并查看实时命令和输出。界面语言可在应用菜单的 **Language / 语言** 中切换，重启后生效。

通过页面按钮或协议链接启动时，客户端会自动连接；请只打开来自可信任发起人的连接链接。

终端客户端启动时可以使用 `-connection-mode=temporary` 或 `-connection-mode=persistent` 指定连接模式，默认值为 `temporary`。使用一键连接或邀请时，以授权步骤中选择的模式为准。

一键连接下载的客户端会保留在本机缓存中；关闭客户端后可以删除：

| 系统 | 缓存目录 |
| --- | --- |
| macOS | `~/Library/Caches/Agenterm` |
| Linux | `${XDG_CACHE_HOME:-~/.cache}/agenterm` |
| Windows | `%LOCALAPPDATA%\Agenterm\cache` |

## ❓ 常见问题

### 连接失败或邀请过期

确认 Agent 和目标电脑都能访问服务地址；`127.0.0.1` 只能在同一台电脑上使用。邀请无法使用时，让 Agent 重新创建。若提示版本不兼容，请使用同一版本的服务端和客户端；若提示已有连接，请先关闭另一客户端。

### 网络断开后怎么办

客户端会自动尝试重连，但不会重放命令。让 Agent 检查设备和任务状态后再继续；已经结束的 Agent 对话不会因设备重新上线而自动唤醒。

### 支持远程桌面吗？

Agenterm 提供终端协助，不提供远程桌面。Windows 支持简单的交互输入；需要真实终端的全屏程序可能无法使用。

### 如何传输文件？

可以让 Agent 协助发起 P2P 文件传输。该方式需要双方能够建立直连，当前支持单文件传输；更多信息见 [P2P 组件说明](../tools/p2p-cli/README.md)。

### 权限与隐私

连接授予目标电脑当前用户的终端权限，仅向信任的人授权。Agent、服务端和目标客户端都能看到命令和输出；请私密保管邀请与令牌，避免通过会话传递密码等敏感信息。断开连接不能撤销已经完成的操作；在不可信网络中请使用 HTTPS。

开发者可查阅 [MCP 工具技术参考](mcp-tools.zh-CN.md)。
