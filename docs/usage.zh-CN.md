## 接入 Agent

### 🤖 让 Agent 帮你配置

将下面的内容发给你的 Agent：

```text
请帮我把 Agenterm 配置为当前 Agent 的 MCP 服务，使用 Streamable HTTP，地址是 https://agenterm.net/mcp。请保留已有配置，完成后检查连接状态，并告诉我是否需要重启或重新加载。配置完成并连接成功后，请生成一个远程邀请令牌。
```

### ⚙️ 手动配置

以下示例使用 Agenterm 托管服务。已有配置文件时，只需合并对应的 `agenterm` 条目，不要覆盖其他配置。

**Codex**：在终端运行（适用于 CLI 和 IDE 扩展）：

```sh
codex mcp add agenterm --url https://agenterm.net/mcp
```

**Claude Code**：在终端运行，添加到当前用户的所有项目：

```sh
claude mcp add --transport http --scope user agenterm https://agenterm.net/mcp
```

**Gemini CLI**：在终端运行，添加到用户配置：

```sh
gemini mcp add --transport http --scope user agenterm https://agenterm.net/mcp
```

添加后重新加载 MCP 配置或重启 Agent，并在其 MCP 设置中确认连接状态。其他支持 Streamable HTTP 的 Agent 也可以使用相同地址。

使用自托管服务时，填入服务启动时显示的 MCP 地址，并在 Agent 中将管理密钥配置为 HTTP Bearer 凭据。请勿将密钥提交到版本库。

## 🤝 开始远程协助

1. 告诉 Agent 要完成的任务，让它为目标电脑创建邀请。
2. 将邀请短链接私下发给目标电脑的使用者。服务端未提供短链接时，发送适合对方系统的连接命令。管理密钥和 `control_token` 由 Agent 保管。
3. 在目标电脑上打开邀请链接，或直接运行收到的连接命令。已安装新版 Rust CLI 时，可在受邀页选择「用过」和「打开终端版」；首次使用或网页无法打开新版客户端时，运行对应系统的命令。核对服务器并允许或拒绝远控的操作都在 CLI 内完成，不在网页上授权。
4. 保持 Agent 对话进行，等待设备上线后开始任务。对方可在客户端查看命令和输出，随时断开连接。
5. 完成后关闭客户端或断开连接。

### 邀请有效期与短码

服务器管理员启用短码后，单设备邀请才会提供短码和短链接。需要连接多台电脑时，让 Agent 创建多设备邀请并分享连接命令，每次操作前说明目标设备。

单设备在线期间，短链接、短码和连接令牌无法用于发起另一条连接。设备断开后，只要令牌仍有效，就可以再次使用。短码第 10 次成功兑换后，短码和短链接失效。打开受邀页面不计入兑换次数。

持久连接成功后，客户端会在本地保存 Server 地址。输入 6 位短码时，可从历史列表中选择生成该短码的 Server；客户端只查询选中的 Server，并沿用记录中的 HTTP 或 HTTPS 协议。没有历史记录时，可直接粘贴受邀短码地址。CLI 将省略协议的地址按 HTTP 处理；使用 HTTPS 时请保留 `https://`。

## 💻 客户端操作

目前维护的客户端为 [Rust CLI](../components/agenterm-cli/README.md)。粘贴连接令牌或短码地址即可连接。使用方向键或鼠标滚轮浏览，拖选文字复制。选中文字后可按 Esc 取消选择，再按 Ctrl+C 断开。临时连接会退出客户端，持久连接会返回连接界面。

临时连接空闲五分钟后自动断开，执行命令的时间不计入空闲时长。持久连接会保持到主动断开。无论从哪种入口打开邀请，都在 CLI 的授权提示中选择连接模式，默认预选临时连接。详见 [Rust CLI 的浏览器协议注册说明](../components/agenterm-cli/README.md#protocol-links)。

选择持久授权后，客户端会在以下目录保留一份可复用的程序。

| 系统 | 缓存目录 |
| --- | --- |
| macOS | `~/Library/Application Support/Agenterm/cli` |
| Linux | `${XDG_CONFIG_HOME:-~/.config}/Agenterm/cli` |
| Windows | `%APPDATA%\Agenterm\cli` |

### 临时连接

发起方可将 `create_client.connection_mode` 设为 `"temporary"`，此时授权菜单只显示临时和拒绝，需要 CLI 0.20.17 或更新版本。

请使用 CLI 0.20.16 或更新版本。运行邀请中的一键命令并选择临时授权后，客户端仅在系统临时目录安装和运行。Agenterm 不把会话输出保存为本地日志，待执行命令可写入临时脚本。正常结束后，引导脚本删除本次下载的客户端和临时文件，协助任务对本机文件和配置的改动会保留。从已安装的客户端发起临时连接时，原有安装会保留。断电或强制关闭引导脚本时，临时文件可能残留。

## ❓ 常见问题

### 连接失败或邀请过期

确认 Agent 和目标电脑都能访问服务地址；`127.0.0.1` 只能在同一台电脑上使用。邀请无法使用时，让 Agent 重新创建。若提示版本不兼容，请用该服务端生成的安装命令安装配套客户端；若提示已有连接，请先关闭另一客户端。

### 网络断开后怎么办

客户端会自动尝试重连，已提交的命令不会重放。单设备的 CLI 进程可以用重连凭据恢复自己的连接，即使服务端还有旧连接记录。请保持客户端运行，重连后让 Agent 检查设备和任务状态再继续。已经结束的 Agent 对话不会因设备重新上线而自动唤醒。

### 支持远程桌面吗？

Agenterm 提供终端协助，不提供远程桌面。Windows 支持简单的交互输入；需要真实终端的全屏程序可能无法使用。

### 如何传输文件？

目标设备通过 Rust CLI 建立持久连接后，可通过 MCP 的 `p2p_transfer_start` 发起直连。两端连通后，可在同一条连接上双向复制文件，每次复制一个文件。关闭客户端会停止其 P2P 组件。详见 [P2P 组件说明](../components/p2p-cli/README.md)。

### 权限与隐私

连接授予目标电脑当前用户的终端权限，仅向信任的人授权。Agent、服务端和目标客户端都能看到命令和输出；请私密保管邀请与令牌，避免通过会话传递密码等敏感信息。断开连接不能撤销已经完成的操作；在不可信网络中请使用 HTTPS。

开发者可查阅 [MCP 工具技术参考](mcp-tools.zh-CN.md)。
